---

## 【技能故事】

> "这个项目值多少钱？"
> 
> 这是投资人问得最多的问题，也是创业者最难回答的问题。

对于成熟企业，我们有成熟的估值方法：DCF、PE、PS...但对于早期项目，这些方法都失效了——没有稳定收入，没有可预测的增长，甚至连产品都还在打磨。

于是，估值变成了"拍脑袋"：投资人凭经验，创业者凭情怀，最后成交价往往是双方博弈的结果，而非价值判断。

我见过太多这样的场景：
- 创业者高估项目，错过融资窗口
- 投资人低估项目，错失优质标的
- 双方在估值上纠缠数月，贻误战机

**有没有一种方法，能让早期项目估值变得有理有据？**

这就是**AI项目估值Skill**诞生的初衷。

---

## 【核心创新：太极八卦评分法】

我们借鉴了太极哲学的阴阳平衡理论，构建了"八卦评分体系"：

```
              ☰ 乾 (技术壁垒)
                  │
    ☴ 巽(生态)──┼──☲ 离(市场)
       │        │        │
  ☷ 坤 ─────┼────── ☵ 坎
  (资源)      │      (风险)
       │        │        │
  ☳ 震 ─────┼────── ☶ 艮
  (增长)      │      (稳定)
       │        │
    ☱ 兑(变现) ─┘
```

**八个维度，全面评估项目价值**：
- ☰ **乾（技术壁垒）**：核心技术领先程度、专利布局、模型性能
- ☷ **坤（资源禀赋）**：团队规模、融资能力、算力资源
- ☲ **离（市场热度）**：赛道关注度、媒体曝光、投资热度
- ☵ **坎（风险评估）**：竞争激烈度、替代风险、政策风险
- ☶ **艮（稳定性）**：收入稳定性、客户留存、合同期限
- ☳ **震（增长动能）**：增长速度、扩张能力、产品矩阵
- ☴ **巽（生态连接）**：合作伙伴、开发者社区、平台集成
- ☱ **兑（商业变现）**：变现能力、毛利率、单位经济

**太极评分→估值系数转换**：
- 90分 → 1.4x（阳盛，强势项目）
- 75分 → 1.25x（平衡偏阳）
- 50分 → 1.0x（平衡）
- 30分 → 0.8x（阴盛，需加强）
